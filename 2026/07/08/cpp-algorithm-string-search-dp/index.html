这篇博客整理了字符串算法、基础搜索和动态规划的核心知识点，方便自己复习和补充。内容尽量精简，聚焦核心思想和模板代码，后续会不断补充细节和题目。

字符串算法

KMP 算法

解决什么问题： 在主串 S 中查找模式串 P 的所有出现位置，时间复杂度 O(n + m)。

核心思想： 当匹配失败时，不要从头重新比较，而是利用已经匹配过的信息，通过 next 数组（失配指针）将模式串尽可能右移。

next 数组的含义： next[i] 表示 P[0..i] 这个前缀中，最长的「真前缀 = 真后缀」的长度。也就是失败后，模式串可以跳到的位置。

要点：

  • next 数组构建和匹配过程几乎一样，都是「失配回退」的逻辑
  • 时间复杂度 O(n + m)，远优于暴力匹配的 O(nm)

字典树 Trie

解决什么问题： 高效地存储和检索字符串集合，支持前缀查询。插入和查询都是 O(L)，L 为字符串长度。

核心思想： 把所有字符串存到一棵树上，公共前缀共享同一条路径。

要点：

  • 根节点是空的，每个节点最多 CH 个子节点
  • cnt[u] > 0 表示有单词以该节点结尾
  • 可扩展支持：前缀计数、删除、最长公共前缀等

AC 自动机

解决什么问题： 在一个主串中同时匹配多个模式串。KMP 是一对一，AC 自动机是一对多。

核心思想： Trie + KMP 的 fail 指针。把所有模式串建成一棵 Trie，然后在每个节点上构建一个 fail 指针，指向当前路径对应的「最长真后缀」所在的节点。

fail 指针的含义： 和 KMP 的 next 数组本质上一样——当前匹配失败时，应该跳到哪个节点继续匹配。

要点：

  • buildFail() 用 BFS 逐层构建，路径压缩后匹配时不用循环跳 fail
  • 时间复杂度 O(n + m)，n 是主串长度，m 是所有模式串长度之和
  • 是 KMP 在多模式串上的推广

Manacher 算法

解决什么问题： 求字符串中最长回文子串的长度。O(n)。

核心思想： 利用回文的对称性，避免重复扩展。维护一个当前已知的最右回文右边界和其中心，新位置可以利用对称位置已算好的回文半径作为初始值。

预处理： 在字符间插入特殊分隔符（如 #），把奇偶长度的回文统一处理。

要点：

  • p[i] 是以 i 为中心的最长回文「半径」
  • 预处理后所有回文都是奇数长度，统一处理
  • 关键：if (i < R) p[i] = min(R - i, p[mirror]) 利用对称性跳过已知部分

后缀数组 SA

解决什么问题： 将字符串的所有后缀按字典序排序，可用于解决最长重复子串、不同子串个数等问题。构建 O(n log n) 或 O(n)，LCP 查询 O(1)。

核心概念：

  • sa[i]：排名第 i 小的后缀的起始位置
  • rk[i]：后缀 S[i..] 的排名
  • height[i]：sa[i] 和 sa[i-1] 的最长公共前缀（LCP）

要点：

  • sa[i] 和 rk[i] 互为逆映射
  • height[i] 是 SA 的核心，很多问题转化为 height 上的 RMQ
  • 倍增法构建 O(n log n)，更快的有 SA-IS 的 O(n) 算法
  • 应用：最长重复子串、不同子串个数 = n*(n+1)/2 - sum(height)

基础搜索

DFS 深度优先搜索

核心思想： 一条路走到底，走不通了就回溯。用递归（或显式栈）实现。

要点：

  • 回溯 = 选择 + 递归 + 撤销选择
  • 适合：连通性问题、排列组合、路径搜索
  • 注意防止重复访问（visited 数组）

BFS 广度优先搜索

核心思想： 一层一层扩展，用队列实现。保证先到的一定是步数最少的。

要点：

  • BFS 天然求最短路径（无权图）
  • 入队时标记 visited，防止重复入队
  • 扩展：双向 BFS、优先队列 BFS（Dijkstra）

DFS vs BFS 对比

特性 DFS BFS
数据结构 栈/递归 队列
空间复杂度 O(h)（h 是深度） O(w)（w 是宽度）
最短路 不保证 保证（无权图）
适用场景 连通性、排列组合 最短路径、层级遍历
实现方式 递归（或显式栈） 队列迭代

动态规划 DP

核心思想： 把大问题拆成小问题，记录小问题的答案避免重复计算。

三要素：

  1. 状态定义：dp[i] 代表什么
  2. 状态转移方程：dp[i] 怎么从 dp[i-1] 等推出来
  3. 边界条件：dp[0]、dp[1] 等初始值

一维 DP

爬楼梯

每次走 1 或 2 步，走到第 n 级有多少种走法？

状态：dp[i] = 走到第 i 级的方案数
转移：dp[i] = dp[i-1] + dp[i-2]
边界：dp[1] = 1, dp[2] = 2

经典：最长递增子序列 LIS

二维 DP

经典：最长公共子序列 LCS

状态：dp[i][j] = s1 前 i 个字符和 s2 前 j 个字符的 LCS
转移：字符相同取左上角 +1，不同取左/上的较大值

经典：0-1 背包

有 n 个物品，第 i 个物品重量 w[i]，价值 v[i]，背包容量 W，求最大价值。

状态：dp[j] = 容量为 j 时的最大价值
转移：dp[j] = max(dp[j], dp[j - w[i]] + v[i])
注意： 内层循环必须逆序遍历，否则一个物品会被选多次（变成完全背包）

DP 学习路线

阶段 类型 代表问题
入门 一维 DP 爬楼梯、LIS
进阶 二维 DP LCS、背包
提高 区间 DP 石子合并、回文分割
提高 树形 DP 树的最大独立集
提高 状压 DP 旅行商问题 (TSP)
高阶 数位 DP 统计区间内满足条件的数

小结

算法 时间复杂度 核心思想
KMP O(n + m) 失配指针 / next 数组
Trie O(L) 树形存储公共前缀
AC 自动机 O(n + m) Trie + fail 指针
Manacher O(n) 回文对称性
后缀数组 SA O(n log n) 后缀排序 + LCP
DFS O(V + E) 深度优先 + 回溯
BFS O(V + E) 队列 + 层序扩展
DP 视状态数而定 状态转移 + 记忆化
