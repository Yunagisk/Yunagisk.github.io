常用指令速查表

以下命令在项目的 Git 仓库目录中执行，feat/gravity 是功能分支名称示例，可替换为自己的分支名。

分类 指令 用途
查看状态 git status 查看当前分支，以及文件的新增、修改、删除和暂存状态。
远端配置 git remote -v 查看远端名称及拉取、推送地址；这条命令不会测试网络连接。
连接检查 git ls-remote origin 尝试读取远端；能列出提交编号和分支等引用，说明远端读取连接正常，但不代表拥有推送权限。
SSH 认证 ssh -T git@github.com 检查 GitHub 的 SSH 身份认证，适用于使用 SSH 地址关联的仓库。
获取更新 git fetch origin 获取远端提交和分支信息，不会自动合并到当前分支，也不会改动当前工作文件。
查看分支 git branch 查看本地分支，带 * 的是当前分支。
新建分支 git switch -c feat/gravity 创建并切换到重力功能分支。
切换分支 git switch main 切回主分支。
首次推送分支 git push -u origin feat/gravity 首次上传这个分支，并建立本地分支与远端分支的跟踪关系。
日常推送 git push 在默认推送配置下，建立跟踪关系后，上传当前分支的本地提交。
合并分支 git merge feat/gravity 将重力功能分支合并到当前所在分支；如果要合入主分支，先执行 git switch main。

切换或合并分支前，先用 git status 检查并处理未提交的修改。合并时若出现冲突，需要解决冲突后再提交。合并成功后，执行 git push 才会把合并结果上传到远端。

文件 用途
.gitignore 排除缓存、临时文件和打包产物，让它们不进入版本控制。
.gitattributes 指定哪些素材由 Git LFS 管理；这些素材仍会上传，只是采用 LFS 存储。

以下模板参考已有的 AngryCat 项目，并补充了常见的编辑器和系统文件规则。本例假设 Git 仓库根目录就是 Unity 工程根目录，两个文件都放在 Assets、Packages、ProjectSettings 的同一级。

用文本编辑器新建文件，分别复制下面的内容并保存。文件名必须是 .gitignore 和 .gitattributes，不要多出 .txt 后缀。已有配置时，保留项目自定义规则，再合并需要的内容。
